사용 규칙

1) 페이지: <html data-wb> + wb.css?v=… + wb-shell.js?v=…(head, 동기) + <header id="wb-shell" data-area=".." data-page="..">
2) 설명·해석 문장은 화면에 쓰지 않는다 → 제목/열 머리 끝 ? :
   <button type="button" class="wb-help" data-help="원문"></button>  · 동적 원문 = data-help-ref="요소id" · HTML 원문 = 자식 <template>
   JS 문자열 템플릿에선 WBShell.helpBtn('원문')
3) 차트: Chart.js → wb-chart.js → 페이지 스크립트. 축·그리드·툴팁 색은 옵션에 쓰지 말 것(defaults 가 테마 따라감).
   시리즈 색 = WBChart.tok('--wb-series-1') (함수라 테마 전환 시 재색칠) · 투명도 = WBChart.tok('--wb-up', .5)
4) 부호색: + = --wb-up(적) · − = --wb-down(청) (시장 관례 — 대시보드·주간 리뷰 공통)
5) ★캐시: netlify.toml 이 /assets/* 를 1년 immutable 캐시 → wb.css·wb-*.js 를 고치면 링크의 ?v= 를 반드시 올린다.
6) 대회 모드(<html data-contest>)면 셸이 contest:true 화면만 노출. 속성을 지우면 전체 IA.
